resumen: "WalkSENS-6M es un sistema biomédico portátil diseñado para el monitoreo automático, simultáneo y continuo de la saturación de oxígeno, la frecuencia cardíaca y la distancia recorrida durante el Test de Caminata de Seis Minutos. El prototipo integra sensores MAX30102 y MPU6050 gestionados por un microcontrolador ESP32, con transmisión inalámbrica vía WiFi hacia una plataforma web desarrollada en Node.js. Mediante técnicas de procesamiento digital de señales, filtrado exponencial y ajuste por regresión lineal, el sistema alcanzó errores de saturación de oxígeno dentro de ±1 a 2 %, una incertidumbre expandida de ±1.24 % para SpO₂, ±0.88 lpm para frecuencia cardíaca y ±1.38 pasos para pedometría. La estimación de distancia presentó un error relativo medio de ±2.18 %, demostrando que el dispositivo constituye una alternativa precisa, accesible y objetiva para la evaluación funcional y el registro clínico digital durante el 6MWT."
